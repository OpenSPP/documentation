# Relevant user guides

This page lists the user guides relevant to OpenSPP DRIMS. These guides are written for logistics officers, warehouse managers, and coordination staff who use the system during disaster response operations.

## Dashboard

- {doc}`DRIMS dashboard </user_guide/drims/dashboard>` — Monitor key indicators, stock levels, and active incidents from the operations dashboard

## Donations

- {doc}`Manage donations </user_guide/drims/donations>` — Record, track, and process incoming donations from agencies and partners

## Requests

- {doc}`Manage supply requests </user_guide/drims/requests>` — Submit and track relief supply requests from field teams

## Dispatches

- {doc}`Manage dispatches </user_guide/drims/dispatches>` — Process picking, packing, waybill generation, and proof of delivery for outgoing supplies

## Inventory

- {doc}`Manage inventory </user_guide/drims/manage_inventory>` — Monitor warehouse stock levels, lot tracking, and expiry dates

## Returns

- {doc}`Manage returns </user_guide/drims/returns>` — Process returned or unused supplies back into warehouse stock

## Approvals

- {doc}`Process approval requests </user_guide/approvals/manage_approvals>` — Review and act on pending approvals for requests and dispatches
