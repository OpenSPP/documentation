# Relevant configuration guides

This page lists the configuration guides relevant to OpenSPP Social Registry. These guides are written for implementers and technical staff who configure the system to meet program requirements.

- {doc}`Configure consent management </config_guide/consent/index>` — Set up privacy notices, consent flows, and API consent filtering
