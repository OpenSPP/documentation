# Relevant configuration guides

This page will list the configuration guides for the OpenSPP Disability Registry. These guides are written for implementers and technical staff who set up the system for disability-inclusive programs.

:::{note}
Configuration guides for the Disability Registry are not yet available. The following topics are planned:

- **Configure vocabularies** — Set up impairment types, causes, severity levels, and assistive device types using the vocabulary system
- **Configure approval workflows** — Define the approval chain for disability assessments before results become active
- **Set up user roles and access** — Assign roles for assessors, reviewers, and program staff with appropriate access controls
- **Configure CEL eligibility functions** — Use disability CEL functions in program eligibility and entitlement rules
:::
