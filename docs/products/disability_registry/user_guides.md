# Relevant user guides

This page will list the user guides for the OpenSPP Disability Registry. These guides are written for assessment officers, social workers, and program staff who conduct disability assessments and manage assistive device requests.

:::{note}
User guides for the Disability Registry are not yet available. The following topics are planned:

- **Conduct a disability assessment** — Record a WG-SS or CFM assessment for an individual registrant
- **Review and approve an assessment** — Process assessments through the approval workflow
- **Manage assistive devices** — Record device needs, track requests, and confirm provisions
- **Search by disability status** — Filter the registry by disability indicators for program targeting
- **Use disability criteria in eligibility rules** — Apply CEL functions in program eligibility configuration
:::
