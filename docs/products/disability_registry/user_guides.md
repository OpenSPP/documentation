# Relevant user guides

This page lists the user guides relevant to the OpenSPP Disability Registry. These guides are written for assessment officers, social workers, and program staff who conduct disability assessments and manage assistive device requests.

## Disability registry

- {doc}`Disability registry overview </user_guide/disability_registry/index>` — Roles, assessment types, and review categories
- {doc}`Conduct a disability assessment </user_guide/disability_registry/conduct_assessment>` — Record a WG-SS or CFM assessment for an individual registrant
- {doc}`Review and approve an assessment </user_guide/disability_registry/review_approve_assessment>` — Process assessments through the approval workflow
- {doc}`Manage assistive devices </user_guide/disability_registry/manage_assistive_devices>` — Record device needs, track requests, and confirm provisions
- {doc}`Search by disability status </user_guide/disability_registry/search_disability_status>` — Filter the registry by disability indicators for program targeting

```{note}
Configuring disability criteria in program eligibility rules (CEL functions) is covered in the {doc}`Relevant configuration guides </products/disability_registry/config_guides>`, written for implementers.
```
