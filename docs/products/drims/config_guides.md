# Relevant configuration guides

This page lists the configuration guides relevant to OpenSPP DRIMS. These guides are written for implementers and technical staff who configure the system for disaster response operations.

## Identity and access

- {doc}`Create and assign user roles </config_guide/role_configuration/index>` — Define roles, assign permissions, and control area-based access for response personnel

## DRIMS configuration

- {doc}`Configure warehouses </config_guide/drims/warehouses>` — Set up central, regional, and mobile warehouses with geographic area assignments
- {doc}`Configure vocabularies </config_guide/drims/vocabularies>` — Define product categories, humanitarian clusters, and donor types
- {doc}`Configure approval chains </config_guide/drims/approval_chains>` — Set up multi-tier approval workflows for requests and dispatches
- {doc}`Configure alerts </config_guide/drims/alerts>` — Define low-stock thresholds, SLA breach rules, and notification triggers

## Area and GIS

- {doc}`Set up administrative areas </config_guide/area_management/index>` — Import and configure geographic area hierarchies for incident and warehouse mapping
- {doc}`Configure GIS data layers </config_guide/gis/index>` — Set up geographic data layers and map report templates for operational visibility

## Monitoring and accountability

- {doc}`Configure audit logging </config_guide/audit/index>` — Enable and customize audit trail settings for all DRIMS operations
