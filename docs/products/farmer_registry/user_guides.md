# Relevant user guides

This page lists the user guides relevant to OpenSPP Farmer Registry. These guides are written for government staff, field officers, and agricultural program operators who use the system day-to-day.

## Getting started

- {doc}`Navigate the OpenSPP interface </user_guide/getting_started/navigation>` — Learn the main menu, search, and navigation patterns
- {doc}`Set up role-based access </user_guide/getting_started/administrating_role_based_access>` — Assign users to roles and areas

## Registry

- {doc}`Register an individual </user_guide/registry/register_individual>` — Create a new individual registrant record
- {doc}`Register a group or household </user_guide/registry/register_group>` — Create a household and add members
- {doc}`Farmer registry fields </user_guide/registry/farmer_registry>` — Record farmer-specific data including farm activities, land parcels, and livestock
- {doc}`Search and filter registrants </user_guide/registry/search_filter>` — Find records using the search portal
- {doc}`Import registrant data </user_guide/registry/import_data>` — Bulk import registrants from a spreadsheet
- {doc}`Export registrant data </user_guide/registry/export_data>` — Export registry data for reporting

## GIS and maps

- {doc}`Maps and geographic reports </user_guide/gis/maps_and_reports>` — View farm locations and generate geographic reports

## Programs

- {doc}`Create a social protection program </user_guide/programs/create_programs>` — Set up a new program with benefit type and eligibility
- {doc}`Enroll beneficiaries </user_guide/programs/enroll_beneficiaries>` — Add eligible registrants to a program
- {doc}`Manage entitlements </user_guide/programs/manage_entitlements>` — View and process beneficiary entitlements
- {doc}`Run program cycles </user_guide/programs/program_cycles>` — Create and manage disbursement cycles
- {doc}`Allocate funds to a cycle </user_guide/programs/allocate_funds>` — Assign a budget to a program cycle
