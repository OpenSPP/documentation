# Try OpenSPP Farmer Registry

**{doc}`OpenSPP Farmer Registry <../../../products/farmer_registry/index>`** is a digital platform for managing agricultural data and delivering farmer support programs. It handles farm household registration, land parcels, crop and livestock tracking, and program enrollment — from eligibility assessment through payment disbursement. Ideal for agricultural input subsidies, climate resilience programs, and rural development initiatives.

To familiarize yourself with the functionalities included in the OpenSPP Farmer Registry product, you can use the specific demo data module, read more under {doc}`Install demo data <install_data>`.

## What you'll get

After loading the Farmer Registry demo data, you'll have:

- **5 agricultural programs** — Input Subsidy, Livestock Support, Aquaculture Support, Equipment Grant, and Climate Resilience
- **8 farm stories** — Fixed smallholder farms with complete registration data, activities, land parcels, and payment histories
- **3 edge case farms** — Boundary farms that demonstrate eligibility rejection paths
- **2 cooperatives** — Group-of-groups records demonstrating federation structures
- **10 change requests** — Covering all six CR states across two CR types
- **Demo users** — Role-gated accounts for exercises involving approval workflows and CR validation
