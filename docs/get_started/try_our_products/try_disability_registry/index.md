# Try OpenSPP Disability Registry

**{doc}`OpenSPP Disability Registry <../../../products/disability_registry/index>`** is a digital platform for standardized disability assessment and inclusive program targeting. It implements internationally recognized instruments — the Washington Group Short Set (WG-SS) for adults and the UNICEF Child Functioning Module (CFM) for children — and links assessment results to assistive device management and program eligibility targeting.

To familiarize yourself with the functionalities, load the demo data (see {doc}`install_data`) and then follow the guided stories and scenarios.

## What you'll get

After loading the Disability Registry demo data, you'll have:

- **10 registrant stories** — Filipino-themed personas covering adults, school-age children, and toddlers across six Philippine regions
- **All 3 assessment instruments** — WG-SS (adults 18+), CFM 5–17 (children 5–17), and CFM 2–4 (toddlers 2–4)
- **All 3 assessment states** — 6 approved, 3 pending, 1 draft
- **All 3 review categories** — MIE (12-month), MIP (36-month), and MINE (72-month)
- **Multiple impairment types per assessment** — physical, sensory, cognitive, psychosocial, and communication
- **Full assistive device lifecycle** — devices at needed, requested, and provided status
- **5 disability-aware programs** — using CEL functions (`has_disability`, `is_severe_disability`, `has_unmet_device_need`, `needs_reassessment`)
- **~200 volume registrants** — generated from blueprints to populate list views, filters, and reports
