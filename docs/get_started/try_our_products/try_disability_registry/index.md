# Try OpenSPP Disability Registry

**{doc}`OpenSPP Disability Registry <../../../products/disability_registry/index>`** is a digital platform for standardized disability assessment and inclusive program targeting. It implements internationally recognized instruments — the Washington Group Short Set (WG-SS) for adults and the UNICEF Child Functioning Module (CFM) for children — and links assessment results to assistive device management and program eligibility targeting.

To familiarize yourself with the functionalities included in the OpenSPP Disability Registry product, you can use the built-in demo data, read more under {doc}`Install demo data <install_data>`.

## What you'll get

After loading the Disability Registry demo data, you'll have:

- **3 registrant stories** — One adult with an approved assessment, one child with a pending assessment, and one adult with a draft assessment showing no disability
- **3 assessments** — Covering the full approval lifecycle: draft, pending, and approved
- **3 assistive devices** — Covering all three device statuses: needed, requested, and provided
